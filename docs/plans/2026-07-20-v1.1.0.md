# Polish Academic MCP 1.1.0 Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Przygotować lokalny serwer MCP dystrybuowany wyłącznie przez npm i uruchamiany poleceniem `npx -y polish-academic-mcp`, z polskimi opisami, wiarygodnymi wynikami live i zweryfikowaną kompatybilnością klientów.

**Architecture:** Zachowujemy pojedynczy proces Node.js komunikujący się przez stdio, 85 stabilnych identyfikatorów narzędzi oraz cache w pamięci. Usuwamy MCPB, ewaluacje badawcze i telemetrię. Wspólna warstwa pobierania otrzyma timeout 30 sekund i jedną ponowną próbę dla błędów przejściowych. Testy bez sieci weryfikują kontrakt MCP i pakiet, a osobny live smoke sprawdza semantykę 82 publicznych narzędzi oraz trzy warunkowe narzędzia PBN.

**Tech Stack:** TypeScript, Node.js 18+, npm, `@modelcontextprotocol/sdk` v1, Zod, wbudowany `node:test`, GitHub Actions.
